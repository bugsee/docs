:::warning[Beta]
This page documents the Bugsee JavaScript SDK, which is in beta (0.1.x) and can change between betas.
:::

The SDK is published as 49 npm packages under the `@bugsee` scope. You install only a few of them. The rest are building blocks that the packages you install depend on, and their APIs can change without notice.

All packages share one version (currently 0.1.0-beta.9), ship ESM and CommonJS builds, and target ES2022. Keep every `@bugsee/*` package in your project at the same version. Install without a tag, for example `npm install @bugsee/bugsee`; the npm `latest` tag currently points at the current beta.

### Platform builds

<a class="external-link external-link-icon" href="https://www.npmjs.com/package/@bugsee/browser" target="_blank" rel="noopener noreferrer nofollow"><code>@bugsee/browser</code></a> and <a class="external-link external-link-icon" href="https://www.npmjs.com/package/@bugsee/node" target="_blank" rel="noopener noreferrer nofollow"><code>@bugsee/node</code></a> are the platform builds the umbrella wraps and selects for you by `exports` condition. Other packages (the adapters, Bun and Electron) build on them. Install `@bugsee/bugsee` instead.
