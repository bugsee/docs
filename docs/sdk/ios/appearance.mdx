`+[Bugsee getAppearance]` returns the shared `BugseeTheme`. Set its properties to change the colors and placeholder texts of the report dialog and of the [feedback](/sdk/ios/feedback/) screen. A property you leave unset keeps its default, which depends on the [style](#style).

<Tabs groupId="lang-ios">
  <TabItem value="objective-c" label="Objective-C">

```objectivec
BugseeTheme *theme = [Bugsee getAppearance];
theme.reportBackgroundColor = [UIColor darkGrayColor];
theme.reportNavigationBarColor = [UIColor blackColor];
theme.reportTextColor = [UIColor whiteColor];

theme.reportSummaryPlaceholder = @"What happened? Briefly";
theme.reportDescriptionPlaceholder = @"Describe what you did and what went wrong";
```

  </TabItem>
  <TabItem value="swift" label="Swift">

```swift
let theme = Bugsee.getAppearance()
theme.reportBackgroundColor = .darkGray
theme.reportNavigationBarColor = .black
theme.reportTextColor = .white

theme.reportSummaryPlaceholder = "What happened? Briefly"
theme.reportDescriptionPlaceholder = "Describe what you did and what went wrong"
```

  </TabItem>
</Tabs>

## Report dialog

| Property | What it sets |
| --- | --- |
| `reportBackgroundColor` | Background of the report dialog. |
| `reportNavigationBarColor` | Background of the navigation bar. |
| `reportCellBackgroundColor` | Background of the table cells. |
| `reportTextColor` | Text color of the labels. |
| `reportPlaceholderColor` | Placeholder color of the input fields. |
| `reportVersionColor` | Text color of the version label. |
| `reportSummaryPlaceholder` | Placeholder of the Summary field. |
| `reportDescriptionPlaceholder` | Placeholder of the Description field. |
| `reportEmailPlaceholder` | Placeholder of the Email field. |
| `reportLabelsPlaceholder` | Placeholder of the Labels field. |
| `reportCloseButtonColor` | Deprecated and not applied: the report dialog uses the system Cancel button. |
| `reportSendButtonColor` | Deprecated and not applied: the report dialog uses the system Done button. |

Which fields the dialog shows and requires is set with launch options, such as `BugseeOptionReportingUILabelsEnabled` and `BugseeOptionReportingUIEmailRequired`; see [Configuration](/sdk/ios/configuration/#reporting).

## Feedback screen

The feedback screen ships in the separate `BugseeFeedback` package. It is drawn in system colors and reads these theme properties:

| Property | What it sets |
| --- | --- |
| `feedbackBackgroundColor` | Background of the chat. Defaults to the system background. A fixed (not dynamic) color also picks the light or dark interface style of the chat, so its system-colored text stays readable. |
| `feedbackEmailBackgroundColor` | Background of the screen that asks for the user's email before the chat. |
| `feedbackEmailContinueActiveColor` | Background of the Continue button once the email is valid. |
| `feedbackEmailContinueNotActiveColor` | Background of the Continue button while the email is not valid. |
| `feedbackEmailSkipColor` | Text color of the Skip button. |

The other `feedback*` properties of `BugseeTheme` — `feedbackBarsColor`, `feedbackNavigationBarColor`, `feedbackTitleTextColor`, `feedbackCloseButtonColor`, `feedbackIncomingBubbleColor`, `feedbackOutgoingBubbleColor`, `feedbackIncomingTextColor`, `feedbackOutgoingTextColor`, `feedbackInputBackgroundColor` and `feedbackInputTextColor` — still compile, but the 7.x feedback screen does not apply them.

## Style

The style picks the default colors of the report dialog. Set it with the `BugseeOptionReportingUIStyle` launch option, or the `bugseeStyle` property of `BugseeOptions`:

| Value | Default colors |
| --- | --- |
| `BugseeStyleSystem` | System colors, which follow the device's light or dark mode. The default. |
| `BugseeStyleLight` | A fixed light palette. |
| `BugseeStyleDusk` | A fixed dark palette. |
| `BugseeStyleBasedOnStatusBar` | Dusk when the status bar shows light content, Light otherwise. |

<Tabs groupId="lang-ios">
  <TabItem value="objective-c" label="Objective-C">

```objectivec
BugseeOptions *options = [BugseeOptions defaultOptions];
options.bugseeStyle = BugseeStyleDusk;

[Bugsee launchWithToken:@"<your_app_token>" options:options];
```

  </TabItem>
  <TabItem value="swift" label="Swift">

```swift
let options = BugseeOptions.default()
options.bugseeStyle = BugseeStyleDusk

Bugsee.launch(token: "<your_app_token>", options: options)
```

  </TabItem>
</Tabs>

Bugsee applies the option to the theme each time the report dialog opens, so set the style through the option rather than through the theme's `style` property. Colors you set on the theme take precedence over the style's defaults.
